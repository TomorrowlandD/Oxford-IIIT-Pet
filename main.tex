\section{实验目的及内容}

本实验围绕 Oxford-IIIT Pet 数据集完成宠物品种分类与宠物前景语义分割两个任务。分类任务以 37 类宠物品种识别为目标，使用 ResNet18 作为 baseline，使用 EfficientNet-B0 作为主分类模型；分割任务以宠物前景和背景二分类为目标，使用 DeepLabV3-MobileNetV3 作为主分割模型。

实验内容包括数据读取与固定划分、图像预处理与数据增强、trimap 标注转换、迁移学习模型构建、分类与分割模型训练、测试集指标评估、可视化结果生成以及模型对比分析。

\subsection{实验任务}

\begin{itemize}
  \item 分类任务：输入宠物图像，输出 37 类宠物品种标签。
  \item 分割任务：输入宠物图像，输出宠物前景与背景的二值语义分割 mask。
  \item 对比实验：复用 ResNet18 和 EfficientNet-B0 的分类结果，完成轻量消融分析。
\end{itemize}

\subsection{交付目标}

\begin{itemize}
  \item 形成可复现的训练、评估和可视化脚本。
  \item 保存模型权重、训练日志、指标文件和报告图片。
  \item 基于真实实验输出撰写完整实验报告，并使用 \texttt{xelatex} 编译生成 PDF。
\end{itemize}

\section{实验原理及技术路线}

\subsection{概述}

本实验采用迁移学习方法解决中等规模宠物图像分类问题，并采用语义分割模型完成像素级前景提取。整体流程从数据集读取开始，经过预处理、模型训练和测试评估，最终将指标和可视化结果整理进实验报告。

\subsection{图像分类原理}

图像分类模型将输入图像映射为类别概率分布。对于 37 类宠物品种分类，模型最后一层输出维度为 37，预测类别由最大 logit 或最大 softmax 概率确定。

\subsection{交叉熵损失}

分类和分割训练均使用交叉熵损失。分类任务中，交叉熵用于度量预测类别分布与真实类别标签之间的差异：

\[
\mathcal{L}_{cls} = -\frac{1}{N}\sum_{i=1}^{N}\log p_{i,y_i}
\]

\subsection{迁移学习}

ResNet18 和 EfficientNet-B0 均加载 ImageNet 预训练权重，并将最后分类层替换为 37 类输出层。预训练特征能够加快收敛，并提升小规模训练数据上的泛化能力。

\subsection{语义分割原理}

语义分割模型为每个像素预测类别。本实验将 Oxford-IIIT Pet 的三值 trimap 转换为二值 mask，模型输出为背景和宠物前景两类。像素级预测结果使用 Pixel Accuracy、IoU、mIoU 和 Dice 进行评估。

\subsection{DeepLabV3-MobileNetV3}

DeepLabV3 通过空洞卷积和多尺度上下文建模提升分割能力，MobileNetV3 作为轻量级 backbone 可以降低计算量。本实验将 DeepLabV3-MobileNetV3 的输出头修改为 2 类，用于宠物前景分割。

\section{实验方法、步骤}

\subsection{实验方法}

本实验采用“分类 + 分割”的综合计算机视觉流程。分类任务用于识别 37 类宠物品种，分割任务用于从图像中提取宠物前景区域。两个任务共享同一数据集和固定划分方式，但分别使用适合任务目标的数据预处理、模型结构和评价指标。

\subsubsection{数据划分方法}

使用 TorchVision 的 \texttt{OxfordIIITPet} 数据集接口读取图像、分类标签和分割 trimap。官方 \texttt{trainval} split 按固定随机种子 42 划分为训练集和验证集，官方 \texttt{test} split 保持为最终测试集。划分索引保存为 \texttt{outputs/results/split\_indices\_seed42.json}，保证多次运行使用相同样本划分。数据读取阶段同步统计类别数量、每个 split 的样本数、训练集类别分布以及 trimap 像素值。

\subsubsection{图像预处理与 mask 转换方法}

分类输入尺寸为 $224\times224$，使用 ImageNet mean/std 归一化。训练集使用轻量随机增强，验证集和测试集使用确定性预处理。分割输入尺寸为 $320\times320$，图像使用双线性插值 resize，mask 使用最近邻插值 resize，并保证随机裁剪和水平翻转对图像与 mask 同步生效。

  \item 汇总 ResNet18 与 EfficientNet-B0 的测试结果，形成轻量消融实验表和分析段落。
  \item 整理报告图像、训练曲线、失败案例和原始记录，为结果分析章节提供依据。

\subsubsection{核心代码片段}

trimap 转二值 mask 是分割任务的关键预处理。代码中首先检查输入像素值是否合法，然后按方案 B 将原始值 2 映射为背景 0，将原始值 1 和 3 映射为前景 1。

\begin{lstlisting}[language=Python,caption={trimap 转二值 mask 核心代码}]
def convert_trimap_to_binary_mask(mask):
    invalid = ~((mask == 1) | (mask == 2) | (mask == 3))
    if bool(invalid.any().item()):
        values = sorted(int(v) for v in torch.unique(mask).tolist())
        raise ValueError(f"Unexpected trimap values: {values}")
    return torch.where(mask == 2, torch.zeros_like(mask), torch.ones_like(mask)).long()
\end{lstlisting}

分类模型构建时只替换最后输出层，backbone 仍加载 ImageNet 预训练权重。这样可以复用通用视觉特征，并将输出维度调整为本实验需要的 37 类。

\begin{lstlisting}[language=Python,caption={分类模型输出层替换核心代码}]
model = resnet18(weights=ResNet18_Weights.DEFAULT)
model.fc = nn.Linear(model.fc.in_features, 37)

model = efficientnet_b0(weights=EfficientNet_B0_Weights.DEFAULT)
in_features = model.classifier[-1].in_features
model.classifier[-1] = nn.Linear(in_features, 37)
\end{lstlisting}

分割模型构建时将 DeepLabV3-MobileNetV3 的主输出头和辅助输出头都替换为 2 类卷积层，使模型输出背景和前景两类 logits。

\begin{lstlisting}[language=Python,caption={分割模型输出头替换核心代码}]
model = deeplabv3_mobilenet_v3_large(
    weights=DeepLabV3_MobileNet_V3_Large_Weights.DEFAULT,
    weights_backbone=None,
    aux_loss=True,
)
model.classifier[-1] = nn.Conv2d(model.classifier[-1].in_channels, 2, kernel_size=1)
model.aux_classifier[-1] = nn.Conv2d(model.aux_classifier[-1].in_channels, 2, kernel_size=1)
\end{lstlisting}

训练循环中，每个 epoch 后在验证集上计算指标，并在验证指标提升时保存 checkpoint。分类任务使用 Macro-F1 作为主要保存依据，分割任务使用 mIoU 作为主要保存依据。

\begin{lstlisting}[language=Python,caption={最佳模型保存逻辑示意}]
improved = (val_macro_f1 > best_macro_f1) or (
    val_macro_f1 == best_macro_f1 and val_accuracy > best_accuracy
)
if improved:
    torch.save(
        {
            "epoch": epoch,
            "model_state_dict": model.state_dict(),
            "val_accuracy": val_accuracy,
            "val_macro_f1": val_macro_f1,
        },
        checkpoint_path,
    )
\end{lstlisting}

\subsection{结论与改进方向}

本实验完成了 Oxford-IIIT Pet 数据集上的 37 类宠物品种分类和宠物前景二分类语义分割。分类任务中，ResNet18 baseline 在测试集上取得 Accuracy 0.883074、Macro-F1 0.881759；EfficientNet-B0 主模型取得 Accuracy 0.899700、Macro-F1 0.898173，整体优于 ResNet18。分割任务中，DeepLabV3-MobileNetV3 在测试集上取得 Pixel Accuracy 0.961981、mIoU 0.924921、Dice 0.954638，能够较稳定地提取宠物前景区域。

从错误分析看，分类任务的主要困难来自细粒度品种之间的相似性，尤其是斗牛犬相关类别、长毛猫类别以及深色短毛猫类别。分割任务的主要困难来自复杂毛发边界、低前景背景对比、近景裁剪和标注边界歧义。后续改进可以从三方面展开：第一，引入更细致的数据增强和类别重采样策略，改善易混淆类别的泛化能力；第二，尝试更强的分类 backbone 或细粒度分类方法，例如注意力机制、局部区域特征或多尺度输入；第三，在分割任务中尝试更高输入分辨率、边界损失或后处理方法，以提升毛发和边界区域的分割质量。

总体而言，本实验形成了从数据读取、预处理、模型训练、指标评估到可视化分析的完整流程。所有报告指标均来自保存的日志、权重和评估结果文件，能够支撑课程实验报告的复现和结果分析。
