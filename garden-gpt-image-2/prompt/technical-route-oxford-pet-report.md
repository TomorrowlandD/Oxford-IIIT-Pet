# GPT Image 2 Prompt: Oxford-IIIT Pet 实验技术路线图

生成一张中文学术实验报告风格的技术路线图，用于课程实验报告“二、实验原理及技术路线”部分。

画布与风格：
- 横向 16:9，白色或极浅灰背景。
- 学术论文 method pipeline 风格，几何精确、干净、可打印。
- 使用扁平化矢量图形，不要 3D、阴影、渐变、照片背景或装饰性纹理。
- 字体使用清晰的中文黑体风格，所有中文标签必须可读。
- 主色使用深灰线条，辅色限制为浅蓝、浅绿、浅橙，整体克制。

版式：
- 左侧为“Oxford-IIIT Pet 数据集”输入框，包含小图标：一张宠物图片缩略图、分类标签、trimap 标注。
- 中间分为上下两条并行分支：
  1. 上分支标题“分类任务”
     流程为：图像预处理与增强 -> ResNet18 baseline / EfficientNet-B0 主模型 -> 37 类品种预测 -> Accuracy / Macro-F1 / 混淆矩阵
  2. 下分支标题“分割任务”
     流程为：trimap 转二值 mask -> DeepLabV3-MobileNetV3 -> 前景/背景预测 -> mIoU / Dice / mask 可视化
- 两条分支在右侧汇合到“结果汇总与报告分析”输出框。
- 箭头从左到右，线条清楚，不交叉，不遮挡文字。

必须出现的中文文字：
- Oxford-IIIT Pet 数据集
- 固定随机划分
- 分类任务
- 图像预处理与增强
- ResNet18 baseline
- EfficientNet-B0 主模型
- 37 类品种预测
- Accuracy / Macro-F1
- 分割任务
- trimap 转二值 mask
- DeepLabV3-MobileNetV3
- 前景/背景预测
- mIoU / Dice
- 结果汇总与报告分析

构图要求：
- 每个步骤使用同等大小的圆角矩形框，框内文字水平居中。
- 分类分支与分割分支上下对齐。
- “固定随机划分”放在数据集输入之后、两条分支之前。
- 右侧输出框稍大，表示两个任务共同汇总。
- 图片整体适合插入 LaTeX 报告，宽度占页面 0.9 到 0.95 倍时仍然清晰。
